JESTER — веб-студия для писателя (PWA)

Что есть в этой стартовой версии:
- проекты и рукописи с редактором на странице и автосохранением;
- библиотека персонажей, локаций, предысторий и референсов;
- прикрепление файлов к материалам библиотеки и проектам;
- переход к официальным ChatGPT и Venice в отдельных вкладках;
- копирование запроса и ручной перенос ответа в рукопись;
- экспорт/импорт резервной копии JSON;
- установка на главный экран телефона как PWA после публикации на HTTPS.

ВАЖНО ПРО ИИ:
JESTER не встраивает и не автоматизирует чужие веб-чаты. Для ChatGPT/Venice откроется официальный сайт. Войди там самостоятельно. Чтобы перенести текст: скопируй запрос из JESTER, вставь в чат; ответ скопируй обратно в JESTER. Файлы для чата нужно прикреплять в самом официальном чате.

ХРАНЕНИЕ:
Данные хранятся локально в IndexedDB текущего браузера и профиля устройства. Они не синхронизируются автоматически между разными браузерами/устройствами. Экспортируй резервные копии регулярно. Не очищай данные сайта в браузере без резервной копии.

ПУБЛИКАЦИЯ:
Это статический сайт. Для работы service worker и установки PWA его нужно разместить по HTTPS (например, GitHub Pages). Открой сайт в Chrome на Android → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Сборка не включает сервер, регистрацию Google, API-ключи или серверную синхронизацию. Google-вход на ChatGPT/Venice выполняется на их собственных сайтах и не передаёт JESTER доступ к этим аккаунтам.
